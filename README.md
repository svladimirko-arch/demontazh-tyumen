- `send.php` — приём заявок: валидация, защита от спама, отправка в Telegram и на email

## Что осталось доработать
1. **Заявки**: GitHub Pages — статический хостинг, PHP не исполняется, поэтому `send.php` на сайте не работает. При отправке формы посетитель видит запасной вариант «Позвоните нам». Решения: перенести сайт на PHP-хостинг и заполнить `CONFIG` в `send.php` (`email_to`/`email_from` и/или токен Telegram-бота) либо переделать форму на Formspree/serverless.
2. **Метрика**: вставить счётчик Яндекс.Метрики и вписать ID в `YM_ID` в конце `index.html`. Цели `call_*`, `tg_*`, `max_*`, `form_sent` уже отправляются.
3. **График работы**: подтвердить актуальный график у заказчика и поправить подпись под телефоном + `openingHours` в JSON-LD.
4. **Реквизиты**: добавить ИНН/ОГРН в `privacy.html`, если этого требуют требования к коммерческим сайтам.

## Заявки: настройка send.php
1. В блоке `CONFIG` укажите `email_to`, `email_from` (ящик на домене сайта).
2. Для Telegram: создайте бота у @BotFather → токен в `tg_token`; напишите боту, затем узнайте `chat_id` (например, через @userinfobot или `getUpdates`) → `tg_chat_id`.
3. Укажите `site_host` — ваш домен.
4. Нужен хостинг с PHP 7.4+ и расширением curl. Если PHP нет — форму можно переделать на Formspree/serverless.

Защита от спама: скрытое поле-ловушка, проверка времени заполнения, лимит 5 заявок/час с IP, проверка Origin, фильтр ссылок, очистка ввода.
